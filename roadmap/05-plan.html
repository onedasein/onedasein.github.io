期末 Gate 自检

  • ☐ 3 个探针 repo 全部公开，每个都有 README + 数据
  • ☐ CSAPP lab 完成 ≥3 个（建议：Bomb / Cache / Malloc）
  • ☐ 决策备忘已写，主攻方向已有数据支撑
  • ☐ GitHub 连续提交 ≥15 周，writeup ≥12 篇

  • ☐ 主攻方向有一个能讲 20 分钟的项目，含数据
  • ☐ 投递 ≥20 家，拿到 ≥3 场面试（哪怕全挂也是成功——你要的是反馈）
  • ☐ 能回答 02 / 03 / 04 里对应方向的自测清单 ≥70%

大三上（2027.9 – 2028.1）：最关键的一学期

两件事并行：① 日常实习（争取大厂）；② 12 月起投 2028 暑期实习（有转正通道，最重要的一次投递）。

月 任务
9 6.824 Lab 3–4；简历重构（一页、项目数据化、STAR）
10 投大厂日常实习（基础架构/中间件/AI Infra/算法工程）；面试
11 进入实习或继续面试；实习中主动承担「性能/故障」类任务
12 暑期实习投递开启（阿里/字节/腾讯/美团/华为等），笔试 + 面试
1 面试复盘；寒假集中补短板（按面试反馈，不按学习计划）

Gate

  • ☐ 6.824 全 lab 完成（本方向最强背书之一）
  • ☐ 有一段实习经历（日常实习即可）
  • ☐ 暑期实习投递 ≥15 家，进入流程 ≥3 家

大三下 → 秋招（2028.2 – 2029.1）

  • 2028.2–4：暑期实习面试高峰；每场面试后 24h 内写复盘（问了什么、答砸了什么、下周补什么）。
  • 2028.7–9：暑期实习，目标拿 return offer；没转正也有大厂背书 + 真实系统经验。
  • 2028.8–11：秋招。此时你的简历应该是：1–2 段实习 + 2–3 个带数据的硬核项目 + 6.824/CSAPP 底座。
  • 2029.1：补录/春招兜底。

每周执行模板

周一–周五  每天 30–60min 底座（CSAPP/lab/算法题）
           每天 2–3h 主线（大块时间优先给"要动手写"的任务）
周六       4–6h 副线（另一个方向的探索）
周日       2h 复盘 + 写 writeup + 更新 progress.md + 推 commit

周检查（周日问自己）

  1. 这周有 commit 吗？≥5 个？
  2. 有一样新东西能跑起来吗？
  3. 卡住的点写下来了吗？下周第一个动作是什么？
  4. 有没有「假装学习」（看视频/读文章超过 40% 的时间）？→ 立刻调回动手。

调整规则（现实会打乱计划）

  • 某阶段超时 ≤2 周：正常，顺延，不砍 gate。
  • 超时 >4 周：说明任务定太大，把 milestone 砍一半（砍范围，不砍验收标准）。
  • 拿到实习/面试反馈：以反馈为准，立刻重排优先级——面试问什么就补什么，这是最高效的学习信号。
  • 对方向产生怀疑：允许在学期末重新评估一次，但必须用新的数据（新项目/实习体验），不许凭情绪横跳。
