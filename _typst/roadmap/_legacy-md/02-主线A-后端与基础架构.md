# 02 · 主线 A：后端开发 · 基础架构

> 一句话：这个方向的护城河不在"会写业务代码"，而在**能造轮子、能扛量、能定位故障**。
> 反过来说：只写 CRUD 的"后端"，正是被 AI 压缩得最狠的岗位。

---

## 1. 能力分层（自下而上，缺一层就会在面试里露馅）

```
L4  架构与权衡：CAP、一致性模型选型、容量规划、成本、演进路径
L3  分布式系统：共识、复制、分片、事务、消息语义、容错与混沌
L2  存储与并发：LSM/B+树、WAL、MVCC、锁、无锁、内存管理
L1  单机性能：epoll/io_uring、内存池、零拷贝、缓存友好、profiling
L0  语言与系统：C/C++/Go、Linux、网络、进程线程、syscall
```

**招聘市场上的真相**：L0/L1 决定你能不能拿到面试（很多人在"讲不出一次性能优化"就挂了），
L2/L3 决定你是"普通后端"还是"基础架构/中间件"（溢价主要在这里）。

## 2. 阶梯与产出

### 阶梯 1：单机性能（第 1–3 月，也服务其他两个方向）
| 任务 | 产出 |
|---|---|
| C 写 epoll HTTP 服务器：keep-alive、超时、静态文件、日志 | repo + wrk 压测曲线 |
| 用 `perf`/火焰图找出瓶颈，做一轮优化（内存池 / 减少 syscall / sendfile） | 优化前后 QPS 对比报告 |
| 写一个线程池 + 无锁队列 | 用 TSan 验证无竞争 |

**关键认知**：`strace -c` / `perf top` / 火焰图 是后端工程师的听诊器，越早学会越好。

### 阶梯 2：造轮子（第 3–6 月）——四选一，贪多必失
| 选题 | 难度 | 简历含金量 | 关键知识点 |
|---|---|---|---|
| **mini Raft KV** | ★★★ | 高（6.824 Lab2+3） | 共识、日志复制、快照、线性一致读 |
| **mini MQ**（对标 Kafka 语义） | ★★★ | 高 | 顺序写、零拷贝、分区、消费者组、至少一次/幂等 |
| **mini 存储引擎 / LSM** | ★★★★ | 极高 | WAL、MemTable、Compaction、Bloom Filter、崩溃恢复 |
| **mini 调度器 / RPC 框架** | ★★★ | 中高 | 服务发现、负载均衡、超时重试熔断、代码生成 |

**强烈建议的第一个轮子：mini Raft KV。** 它有现成的 lab 框架可以对照，且面试可讲性最高。

### 阶梯 3：生产化（第 6–12 月）——这一步区分"学生项目"和"工程能力"
- 容器化 + **K8s** 部署（Deployment/Service/ConfigMap/探针），做一次滚动发布与回滚。
- **可观测性**：Prometheus + Grafana 面板 + OpenTelemetry 链路追踪；给系统打上指标（QPS、P99、队列深度、错误率）。
- **压测与容量**：定位 P99 毛刺来源（GC？锁竞争？磁盘 fsync？网络重传？）。
- **故障演练**：杀 leader、网络分区（`tc netem`）、磁盘写满、时钟漂移 —— 记录系统行为与恢复时间。
- 读源码：**etcd → Redis → RocksDB → Envoy**（按复杂度递增，别一上来读 Envoy）。

### 阶梯 4：架构与权衡（贯穿，靠写 writeup 沉淀）
- 用 DDIA 的框架解释你做过的每个决定："为什么这里选 CP 不选 AP""为什么用推不用拉"。
- 能画出你系统的**故障域图**和**容量模型**，并说明单点在哪、怎么破。

## 3. 必须能答出来的面试题（自测清单）

- 一次 HTTP 请求从网卡到你的 handler，中间发生了什么？延迟主要在哪些环节？
- `epoll` 的 LT/ET 区别、惊群问题、为什么需要 `EPOLLONESHOT`？
- Raft 如何保证已提交日志不丢？为什么多数派提交就能保证？
- 线性一致读为什么不能直接读 follower？ReadIndex / lease read 各自解决什么？
- LSM 的写放大/读放大/空间放大如何权衡？为什么需要 Compaction？
- 你的系统 P99 突然从 20ms 涨到 2s，你的排查顺序是什么？（**这题几乎决定你能不能过**）

## 4. 语言选择

| 语言 | 用途 | 建议 |
|---|---|---|
| **C** | 底座、内核、性能 | 必须 |
| **C++** | 存储/中间件/推理引擎（字节、腾讯、华为的基础架构多用） | 选做，学 RAII/智能指针/移动语义/并发 |
| **Go** | 云原生、后端服务（工程效率最高，转正实习友好） | **推荐主力**，2 周即可上手 |
| **Rust** | 新中间件、数据库（TiKV/达梦等） | 加分项，别当第一门语言 |

**结论**：C（底层理解）+ Go（工程交付）这个组合对本科实习生性价比最高；想进基础架构组再补 C++。
