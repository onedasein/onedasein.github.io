# 01 · 共同底座：CSAPP 与系统基础

> 定位：这是三个方向**都要吃的**底座，总投入约 12 个月（每天 0.5–1h 的固定时段 + 项目里的"回头补"）。
> 核心原则：**底座不是先修课，是脚手架。** 做项目 → 卡住 → 按问题回查对应章节，比线性通读快 5 倍、扎实 3 倍。

---

## 1. 学习顺序（有依赖关系的正确拓扑序）

```
① C 语言与内存模型            （2–3 周，必须真会，不是"C 语言语法"）
      ↓
② CSAPP 第 3/5/6 章 + lab      （4–6 周，CPU/优化/存储层次）
      ↓
③ 组装 + 进程 + 虚拟内存        （CSAPP 第 7/8/9 章 + malloclab/shlab）
      ↓
④ 并发与 I/O                  （CSAPP 第 10/12 章，配 epoll 服务器，边做边学）
      ↓
⑤ 网络：CS144                 （4–6 周，自己写 TCP）
      ↓
⑥ OS 全景：OSTEP 或 6.S081     （8–10 周，选一个）
      ↓
⑦ 存储/数据库：15-445          （8–10 周，方向 A 必做，方向 B/C 可只做前 4 个 lab）
      ↓
⑧ 分布式：6.824 / 6.5840       （10–12 周，全 lab；方向 A 必做，B 强烈建议）
```

**并行原则**：⑥⑦⑧ 不要串行等待，可以在"当前主线方向"的项目里用上它们（比如写 KV 时同时吃 15-445 的 B+ 树 lab）。

## 2. C 语言：为什么绕不开，怎么学

**为什么**：读 Linux 源码、内核、CUDA、RocksDB、Redis、PyTorch 的 C++ 层——全部要求你能看懂指针、内存布局、ABI、未定义行为。
只会 Python/Java 的人在做 AI Infra 时会在第一层就卡死。

| 阶段 | 内容 | 验收 |
|---|---|---|
| 1 | 指针与数组的真实关系、`void*`、函数指针、结构体内存对齐 | 能手写通用的 `qsort` 风格回调 |
| 2 | 手动内存管理：`malloc/free` 语义、悬垂指针、double free、内存泄漏检测（ASan/valgrind） | 用 ASan 找出一段故意埋雷代码的所有问题 |
| 3 | 编译链接：`.o/.a/.so`、符号、`nm/objdump/readelf`、静态 vs 动态链接 | 能解释一次 `undefined reference` 到底发生在哪个阶段 |
| 4 | 系统调用与错误处理：`errno`、`EINTR` 重试、`fork/exec/wait` | 手写一个 mini shell（管道 + 重定向） |
| 5 | 并发：`pthread`、互斥锁、条件变量、`volatile`/原子性、内存序入门 | 手写生产者-消费者队列，无数据竞争（TSan 验证） |

**书籍**：K&R（薄，当参考）｜《C 陷阱与缺陷》｜《深入理解 C 指针》｜
**必备实践**：把 CSAPP 的 lab 用 C 全部做掉，这本身就是最好的 C 训练。

## 3. CSAPP 正确读法（重点章节 + lab 优先级）

> 不要说"我要把 CSAPP 读完"。说"我要做掉这 6 个 lab，卡住就回去查章节"。

| Lab | 对应章节 | 优先级 | 耗时 | 学到什么 |
|---|---|---|---|---|
| Data Lab | 第 2 章 | ★★ | 10–15h | 位运算、补码、浮点 IEEE754 |
| Bomb Lab | 第 3 章 | ★★★ | 10–15h | 读汇编、gdb 单步 |
| Attack Lab | 第 3 章 | ★★ | 8–12h | 栈帧、缓冲区溢出、ROP（理解安全的起点） |
| **Cache Lab** | 第 6 章 | ★★★ | 15–20h | 存储层次、局部性、矩阵分块——**直接迁移到 CUDA/性能优化** |
| **Malloc Lab** | 第 9 章 | ★★★ | 20–25h | 显式/隐式空闲链表、碎片、`sbrk`——**存储引擎的种子** |
| **Shell Lab** | 第 8 章 | ★★★ | 15–20h | 进程、信号、作业控制、竞态——**并发直觉的种子** |
| Proxy Lab | 第 10/12 章 | ★★ | 15–20h | 网络编程 + 线程池 + 缓存，最接近"可写进简历的成品" |

**章节精读优先级**：3（汇编）≈ 6（存储层次）≈ 9（虚拟内存）> 5（性能优化）> 8（异常控制流）> 12（并发）> 10（I/O）> 7（链接）> 2（位）。
第 1、11 章扫一眼即可；第 4（处理器体系结构）在第一遍可跳过，等要做 AI Infra 时再回来读。

**常见错误读法**
- ❌ 从第 1 章线性读到第 12 章、每个 lab 都不做 → 3 个月后全部忘记。
- ❌ 直接抄 lab 答案 → 唯一的价值（卡住 3 小时后的顿悟）被你自己删掉了。
- ❌ 把 CSAPP 当成"操作系统课" → 它不教调度/文件系统实现，那些在 OSTEP/6.S081 里。
- ❌ 只读中文版不看 lab handout → lab handout 的英文是你在真实工作里的语言。

## 4. 操作系统：OSTEP vs 6.S081（二选一）

| | [OSTEP](https://pages.cs.wisc.edu/~remzi/OSTEP/) | [MIT 6.S081](https://pdos.csail.mit.edu/6.S081/2021/) |
|---|---|---|
| 形式 | 免费书 + 少量作业 | 视频 + 5 个 xv6 lab |
| 优点 | 讲解极清晰、覆盖全、可快速过 | lab 硬核，写完真的懂内核 |
| 缺点 | 动手少 | 门槛高、耗时 100h+ |
| 建议 | **必读**（选读调度、虚拟内存、并发、文件系统四部分） | 想在系统方向走深就做，或大三上做 |

**产物**：不要只读书。最低配：用 C 写一个 **用户态线程库**（`makecontext/swapcontext` 或 `ucontext`）+ 一个 **slab 分配器**。

## 5. 网络：[CS144](https://cs144.github.io/)（强烈建议全做）

自己实现一个 TCP 接收/发送方：序列号、滑动窗口、重传、拥塞控制雏形。
做完之后，"TCP 为什么这样设计""为什么要有 Nagle""为什么延迟会抖动"这些问题会从背诵变成直觉。

**配套**：《UNIX 网络编程 卷1》选读（IO 模型、`select/poll/epoll`）｜《TCP/IP 详解 卷1》
**产物**：探针 A 的 epoll 服务器 + CS144 的 TCP 实现 = 简历上"网络编程"这条不再是空话。

## 6. 数据库 / 存储：[CMU 15-445](https://15445.courses.cs.cmu.edu/)

方向 A **必做**；方向 B（训练数据管线/Checkpoint）做 BufferPool + B+Tree 即可；方向 C 可跳过。

lab 顺序：Buffer Pool Manager → B+Tree → Query Execution → Concurrency Control（MVCC/锁）。
**产出**：一个能跑 SQL 的 mini 数据库，或一个自研 LSM 引擎（写路径：MemTable → WAL → SSTable → Compaction）。

## 7. 分布式：[MIT 6.824 / 6.5840](https://pdos.csail.mit.edu/6.824/)

| Lab | 内容 | 价值 |
|---|---|---|
| Lab 1 | MapReduce | 入门，快速有成就感 |
| Lab 2 | **Raft**（选举/日志/持久化/快照） | 全课程核心，面试能讲 20 分钟 |
