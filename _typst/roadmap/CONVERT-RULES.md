# Markdown → Typst 转换规范（本目录专用）

> 目标：把 `~/dsh/learning-roadmap/*.md` 逐字保真地转成 Typst 章节文件。
> 版本：Typst 0.15.1（`/home/lp_tower/typst-x86_64-unknown-linux-musl/typst`）
> 风格样本：`00-direction.typ`（**输出必须与它风格一致**）

## 0. 文件结构

每个章节文件的开头固定为：

```typ
#import "lib.typ": *

= 章标题
```

- `= 章标题` 沿用源文档的 H1，**去掉** `00 ·`、`01 ·` 这类编号前缀。
- 章节文件里**不要**写 `#show:`、`set page`、字号等版式——版式全部在 `lib.typ` 里。
- 不要修改 `lib.typ`、`main.typ`、`00-direction.typ` 以及不属于你的章节文件。

## 1. 语法映射

| Markdown | Typst | 说明 |
|---|---|---|
| `# 标题` | `= 标题` | 只出现一次（章标题） |
| `## 标题` | `== 标题` | 保留源文档的手写序号，如 `## 0. 一句话策略` → `== 0. 一句话策略` |
| `### 标题` | `=== 标题` | |
| `**粗体**` | `*粗体*` | Typst 用单星 |
| `_斜体_` | `_斜体_` | 不变 |
| `` `代码` `` | `` `代码` `` | 不变 |
| `> 引用` | `#note[ 引用 ]` | 多行合并成一段 |
| `- 项` | `- 项` | 不变 |
| `1. 项` | `+ 项` | Typst 有序列表用 `+` |
| `- [ ] 项` | `- #todo[项]` | |
| `- [x] 项` | `- #done[项]` | |
| `- ❌ 项` | `- #no[项]` | 删掉 ❌ 本身（本机无该字形） |
| `---` | 删除 | 章节标题已承担分隔作用 |
| Markdown 表格 | `#tbl(列宽, 表头..., 数据..., ...)` | 第一行必须是表头；空单元格写 `[]` |
| `[文字](https://…)` | `#link("https://…")[文字]` | 外链 |
| `[文字](别的文档.md)` / `/roadmap/…` | 纯文字或 `见第 N 章〈章名〉` | **不要**写成链接（同一份 PDF 内部） |
| 代码块 ` ``` ` | 原样保留 | 块内一字不改，含 ASCII 框图 |

## 2. Typst 特殊字符（正文里必须转义）

| 字符 | 写法 | 原因 |
|---|---|---|
| `#` | `\#` | 否则被当成代码 |
| `$` | `\$` | 否则进入数学模式 |
| `@` | `\@` | 否则被当成引用标签 |
| `"` | 换成 `「」` 或 `「」` | Typst 里 `"` 是字符串定界符，会直接编译报错 |
| `~` | `\~` | 否则是不换行空格 |

`≤`、`→`、`★`、`①`、`·`、`—`、`≈` 等符号直接写即可（字体覆盖已确认，唯一例外是 `❌`）。

## 3. `#tbl` 用法

```typ
#tbl(
  (auto, 1.5fr, 1fr),          // 列宽，数量 = 列数
  [表头1], [表头2], [表头3],    // 前 N 个单元格 = 表头（N = 列数）
  [数据], [数据], [数据],       // 之后按行依次排列
  [数据], [数据], [数据],
)
```

- 单元格里可以用 `*粗体*`、`` `代码` ``；空单元格写 `[]`。
- 列宽经验值：短标签列用 `auto`，说明列用 `1fr`～`1.6fr`。

## 4. 保真要求（硬性）

1. 不许增删信息、不许改写措辞、不许省略表格行或列表项。
2. 唯一允许的排版调整：把被硬换行（行尾两空格）切断的句子合并成一段。
3. 表格里单元格内容较长时也**不要**改写成缩写。
4. 源文里的 `**重点**` 一律转成 `*重点*`，不要丢强调。

## 5. 自检（必做，零 warning 才算通过）

```bash
cd /home/lp_tower/dsh/blog/_typst/roadmap
cat > _check_XX.typ <<'EOF'
#import "lib.typ": *
#show: roadmap-doc
#include "你的文件.typ"
EOF
/home/lp_tower/typst-x86_64-unknown-linux-musl/typst compile _check_XX.typ out/check-XX.pdf 2>&1 | head -40
rm -f _check_XX.typ
```

有 error 就修到通过；warning 也要看完（`no text within stars` 说明 `**` 没转成 `*`）。
